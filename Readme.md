# Length-Sensitive DPO

This project explores **length-sensitive Direct Preference Optimization (DPO)**, which is a regularized version of the Direct Preference Optimization used by Wu et al. in their paper **Rethinking Pragmatics in Large Language Models: Towards Open-Ended
Evaluation and Preference Tuning**. The main idea behind this is penalizing larger response generated by DPO-tuned model and negate one of the limitations of the paper which is verbosity.

## Overview

In this project, we have tried to mitigate two of the major limitations mentioned in the paper by Wu et al.

- Verbosity: To introduce some kind of penalty for longer responses. This has been done by introducing regularization on the length difference between the model's response and the gold response. The α parameter acts as the regularization parameter here, with a default value set to 0.01. 

- Judge Bias: In the original paper, only GPT4 was used as a judge in the LNRS metric to evaluate the model's response. To remove this judge bias, we have introduced an ensemble method of 3 judges(can be more or less) and average out their scores. 

## Goals

- Investigate length bias in direct preference-based training.
- Evaluate on both MCQA Accuracy and LNRS(1 judge and ensemble judge).
- Compare length-sensitive methods with standard DPO baselines, an SFT-tuned model, and the base model.
